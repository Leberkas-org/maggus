# Bug: Saving config corrupts TUI layout — top/bottom borders disappear

## Summary

After saving config (via the save button or Ctrl+S), the TUI layout breaks — top and bottom borders disappear and a "Saved C:\...\config.yml" message appears in the bottom left. All subsequent views are also broken until maggus is restarted.

## Steps to Reproduce

1. Open `maggus` → config view
2. Change any setting
3. Press Enter on "Save project config" (or Ctrl+S)
4. Observe: "Saved ..." message appears at bottom left, borders disappear
5. Navigate to any other view (status, menu) — layout is still broken

## Expected Behavior

Saving config should update the status text within the TUI ("Saved project config") without corrupting the terminal. The borders should remain intact.

## Root Cause

`saveConfig()` in `src/cmd/config.go:493` writes directly to stdout:

```go
fmt.Printf("Saved %s\n", path)
```

Bubble Tea owns stdout for rendering. Any direct `fmt.Printf` to stdout while the TUI is active injects a raw line into the terminal output, corrupting Bubble Tea's screen state. The injected line shifts all content down by one row, pushing the top border off the visible area. This corruption persists because Bubble Tea doesn't know the terminal was modified externally — it continues rendering at the wrong offsets.

The `configResultMsg{text: "Saved project config"}` at line 431 already provides the correct in-TUI feedback via `m.statusText`. The `fmt.Printf` is redundant and harmful.

## User Stories
